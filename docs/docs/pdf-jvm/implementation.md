# pdf-jvm - Implementation

The `export/pdf/jvm` module exports the output of a running simulation from the
`engine` core to PDF. It is a JVM-only implementation.

## Add the dependency

```kotlin
dependencies {
    implementation("org.pcsoft.framework:simplay-engine:0.5.1")
    implementation("org.pcsoft.framework:simplay-pdf-jvm:0.5.1")
}
```
