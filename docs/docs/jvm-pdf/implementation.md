# jvm-pdf - Implementation

The `export/jvm-pdf` module exports the output of a running simulation from the
`engine` core to PDF. It is a JVM-only implementation.

## Add the dependency

```kotlin
dependencies {
    implementation("org.pcsoft.framework:simplay-engine:0.3.0")
    implementation("org.pcsoft.framework:simplay-jvm-pdf:0.3.0")
}
```
