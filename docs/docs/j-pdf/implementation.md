# j-pdf - Implementation

The `j-pdf` module exports the output of a running simulation from the `engine`
core to PDF.

## Add the dependency

```kotlin
dependencies {
    implementation("org.pcsoft.framework:simplay-engine:<version>")
    implementation("org.pcsoft.framework:simplay-j-pdf:<version>")
}
```
