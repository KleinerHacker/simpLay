# print-jvm - Implementation

The `export/print/jvm` module sends the output of a running simulation from the `engine`
core to a printer.

## Add the dependency

```kotlin
dependencies {
    implementation("org.pcsoft.framework:simplay-engine:0.4.1")
    implementation("org.pcsoft.framework:simplay-print-jvm:0.4.1")
}
```
