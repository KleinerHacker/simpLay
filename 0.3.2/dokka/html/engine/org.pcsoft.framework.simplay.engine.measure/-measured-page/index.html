MeasuredPage

sealed interface MeasuredPage

A raw Page with its blocks replaced by measured blocks.

The unchanged layout is forwarded to raw by hand. The block list is exposed only as the measured blocks; the raw blocks stay reachable via raw.blocks. contentArea, requiredContentHeight and effectiveSize are derived on the fly. Not persistable.
