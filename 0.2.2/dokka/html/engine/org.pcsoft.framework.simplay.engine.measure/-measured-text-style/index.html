MeasuredTextStyle

class MeasuredTextStyle(val raw: TextStyle, val font: MeasuredFont)

A raw TextStyle with its font replaced by a MeasuredFont and the resolvedLineHeight derived.

The unchanged properties (lineSpacing, alignment) are forwarded to raw by hand. The font is exposed only as the measured font; the raw one stays reachable via raw.font. Not persistable.
