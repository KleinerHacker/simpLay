UnplacedLine

class UnplacedLine(val parts: List<UnplacedPart>, val ascent: Double, val descent: Double)

A line as produced by a LineBreakerStrategy: the parts that belong on one line, already measured but not yet positioned. SimpLayBlockEngine assigns the positions and turns each UnplacedLine into a org.pcsoft.framework.simplay.engine.measure.MeasuredLine.
