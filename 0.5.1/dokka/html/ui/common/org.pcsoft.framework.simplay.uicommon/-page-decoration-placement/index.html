PageDecorationPlacement

data class PageDecorationPlacement(val edge: PageEdge, val alignment: EdgeAlignment = EdgeAlignment.STRETCH, val offsetX: Double = 0.0, val offsetY: Double = 0.0)

Where a single page decoration of a PaperSheetView (fx and swing) is anchored, in the component area around a page (inside outerMargin/pageGap), not in the page content itself. That band is no longer a fixed outerMargin: when the decoration opts into reservation, it grows via resolveReservedMargins/EdgeReservation to fit the decoration's natural size.
