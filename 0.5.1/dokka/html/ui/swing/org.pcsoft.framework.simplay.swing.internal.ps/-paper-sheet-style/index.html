PaperSheetStyle

class PaperSheetStyle(val sheetBackground: Paint = DEFAULT_SHEET_BACKGROUND, val sheetBorderColor: Paint = DEFAULT_SHEET_BORDER_COLOR, val sheetBorderWidth: Double = DEFAULT_SHEET_BORDER_WIDTH, val shadowColor: Paint = DEFAULT_SHADOW_COLOR, val shadowOffset: Double = DEFAULT_SHADOW_OFFSET, val selectionColor: Paint = DEFAULT_SELECTION_COLOR, val caretColor: Color = DEFAULT_CARET_COLOR, val deactivatedSheetBackground: Paint = DEFAULT_DEACTIVATED_SHEET_BACKGROUND, val deactivatedOverlayColor: Paint = DEFAULT_DEACTIVATED_OVERLAY_COLOR)

The visual values a PaperSheetSwingPainter pass draws the sheet chrome, the selection highlight and the caret with. The Swing counterpart of the fx module's PaperSheetStyle; every field defaults to the built-in look, BasicPaperSheetUI fills it from the view's style properties so a Look-and-Feel or a programmatic setter can override it.
