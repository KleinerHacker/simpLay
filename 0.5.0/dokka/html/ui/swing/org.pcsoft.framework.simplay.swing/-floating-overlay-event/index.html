FloatingOverlayEvent

class FloatingOverlayEvent : EventObject

Passed to the FloatingOverlay.onShown and FloatingOverlay.onHidden listeners when the owning PaperSheetView shows or hides an overlay. Carries the same context the read-only overlay fields hold at that moment. The Swing counterpart of the fx module's FloatingOverlayEvent; it extends EventObject instead of a JavaFX Event.
