FloatingOverlayEvent

class FloatingOverlayEvent : Event

Passed to the FloatingOverlay.getOnShown and FloatingOverlay.getOnHidden handlers when the owning PaperSheetView shows or hides an overlay. Carries the same context the read-only overlay fields hold at that moment.
