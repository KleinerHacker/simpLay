PaperSheetMouseEvent

class PaperSheetMouseEvent : EventObject

Passed to PaperSheetView.onMouseEvent while the mouse hovers (Kind.HOVER) or clicks (Kind.CLICK) over a PaperSheetView, carrying the document structure under the pointer. The Swing counterpart of the fx module's PaperSheetMouseEvent; it extends EventObject instead of a JavaFX Event.
