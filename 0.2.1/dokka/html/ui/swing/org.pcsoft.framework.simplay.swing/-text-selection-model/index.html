TextSelectionModel

class TextSelectionModel

The observable selection state of a PaperSheetView plus the commands to change it. One instance lives for the whole life of its view and is reached through PaperSheetView.selectionModel. The Swing counterpart of the fx module's TextSelectionModel.

All state is read-only; the view's UI is the only writer. Besides the plain text the model exposes the character startIndex / endIndex / length in the document's linear text, whether the selection is isEmpty, its bounds in viewport pixels and the styled runs (one per covered text part, carrying the font). selectRange, selectAll and clearSelection drive the selection from code; a command issued before the view has a UI is applied once the UI is attached.

Bound listeners are notified through a PropertyChangeSupport; the property names are the PROP_* constants.
